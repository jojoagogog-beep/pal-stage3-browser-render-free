# PAL Shopify Listing Media Playbook

Purpose: create original App Store media using proven presentation patterns from successful Shopify apps without copying their artwork, wording, branding, or exact layouts.

Official constraints:
- Desktop screenshots: 1600x900, 16:9.
- Provide 3-6 screenshots; at least one must show the actual app UI.
- Crop browser chrome and desktop backgrounds.
- Every image must be unique and show a different feature/view/state.
- Do not use pricing, review scores, statistics, guarantees, unsupported outcome claims, Shopify trademarks, or logo-only screenshots.
- Feature media should have one focal point, high contrast, and clear alt text.
- Promotional feature video: target 2-3 minutes; keep instructional screencast portions limited and focus on merchant value.

Creative pattern:
1. First image = strongest merchant problem/solution + clearest actual UI.
2. Second image = core workflow in one glance.
3. Third image = automation or time-saving feature.
4. Fourth image = risk/issue detection or reporting.
5. Fifth image = settings/customization or integration.
6. Optional sixth image = before/after state only when factual and non-statistical.

Visual system:
- Large real UI crop occupying most of frame.
- Short benefit headline; one idea per image.
- Spacious background, high contrast, consistent typography.
- Use app's own palette; never imitate another app's trade dress.
- No tiny unreadable UI mosaics.
- No generic stock-art-only image.
- No fake merchant data or fabricated results.

Video structure:
- 0-10s: merchant problem and app value.
- 10-35s: show actual dashboard and immediate setup.
- 35-90s: demonstrate 2-3 strongest workflows.
- 90-120s: show result/evidence/history/settings.
- Final: concise value statement and install/use context.
- Use original UI capture, original narration/music if any, no competitor assets.

Benchmark method:
- Before producing media, review at least 8 currently active successful apps in the same or adjacent category.
- Prefer genuine adoption signals: review volume, rating count, Built for Shopify, longevity, and visible current traction; include at least 3 clearly high-adoption examples where available.
- Compare the live listing as a sales surface, not only as a review submission: hero/first-frame hierarchy, UI crop, headline density, screenshot order, feature sequence, trust treatment, and video hook/pacing/ending.
- Write docs/commercial-media-plan.json before accepting the media kit. The plan must explain the role of every screenshot and video segment and why the same files are suitable for the live App Store listing after approval.
- Screenshot 1 must work as a merchant-facing sales hero at thumbnail size and show credible real UI proof.
- The static gallery and video must tell one consistent product story from merchant problem → core workflow → differentiator → evidence/control.
- Never copy exact slogans, screenshots, illustrations, icons, brand colors, composition, layout, or trade dress. Learn patterns only; all PAL assets must be original.
- Review-only placeholder media is not acceptable. If the assets are not good enough to remain on the public listing, regenerate them before submission.
